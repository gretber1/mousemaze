# Мышь в лабиринте

Оконное приложение на Java 21 и Swing: мышь учится находить сыр в лабиринте методом **Q-learning** (обучение с подкреплением). Лабиринт можно сгенерировать или нарисовать кликами, а процесс обучения наблюдать в реальном времени.

Лабораторная работа № 2 по ООП, СПбПУ Петра Великого, ИКНК, ВШ КТИС.

## Возможности

- **Генерация лабиринта** алгоритмом поиска в глубину (DFS, явный стек). Размер задаёт пользователь, дополнительно добавляются петли, вода и молнии.
- **Тонкие стены** между клетками, как в настоящем лабиринте.
- **Редактор кликами:** стены, вода, молнии.
- **Настоящий Q-learning:** мышь не знает карту и число капель воды. В состояние входят координаты и набор уже выпитой воды, поэтому за каждую каплю награда берётся один раз за эпоху.
- **Панель управления:** старт и пауза, один шаг, одна эпоха, N эпох подряд, скорость анимации, показ лучшего пути без случайных ходов.
- **Статистика:** номер эпохи, сумма награды, лучший результат, ε, размер Q-таблицы.
- **Настраиваемые параметры:** награды и штрафы, α, γ, ε.

## Правила среды

| Событие | Награда |
|---|---|
| Сыр (Z), конец эпохи | +200 |
| Вода (x), один раз за эпоху | +10 |
| Молния (y) | −20 |
| Шаг | −1 |
| Удар о стену (мышь остаётся на месте) | −5 |

Старт мыши в левом нижнем углу (0, 0), сыр в правом верхнем (W−1, H−1). Значения можно менять в интерфейсе.

## Алгоритм

Обновление Q-таблицы после каждого шага:

```
Q(s, a) ← Q(s, a) + α · [ r + γ · max Q(s′, a′) − Q(s, a) ]
```

Параметры по умолчанию: α = 0,3, γ = 0,97, ε уменьшается от 1,0 до 0,02 (умножение на 0,995 после каждой эпохи). Лимит шагов в эпохе: 6·W·H.

На лабиринте 10×10 после 500 эпох средняя награда составляет около 164 при точном оптимуме около 167 (≈ 98 %).

## Запуск

Нужен только **JDK 21**. Maven, Gradle, JavaFX и `module-info.java` не требуются.

### IntelliJ IDEA

1. File → New → Project: язык Java, Build system: IntelliJ, JDK 21.
2. Скопируйте папку `ru` из `src/` этого репозитория в `src/` вашего проекта.
3. Откройте `ru/spbstu/mousemaze/Main.java` и запустите `main`.

### Командная строка

```bash
mkdir -p out
javac -d out $(find src -name "*.java")
java -cp out ru.spbstu.mousemaze.Main
```

На Windows (PowerShell):

```powershell
mkdir out -Force
javac -d out (Get-ChildItem -Recurse src -Filter *.java).FullName
java -cp out ru.spbstu.mousemaze.Main
```

## Структура проекта

```
src/ru/spbstu/mousemaze/
├── Main.java                 точка входа
├── model/                    Maze, Position, Direction, CellType
├── rl/                       Environment, QLearningAgent, Mouse, Simulation,
│                             State, StepResult, RewardConfig, LearningParams
├── generator/                MazeGenerator (интерфейс), DfsMazeGenerator, GenerationParams
├── view/                     MainFrame (JFrame), MazePanel (JPanel)
└── controller/               AppController
test/Experiments.java         вспомогательная программа для отчёта (не нужна для запуска)
```

Зависимости пакетов: `model` не зависит ни от чего; `rl` и `generator` зависят от `model`; `view` и `controller` связаны между собой и используют остальные пакеты.

## Применённые приёмы ООП

- Инкапсуляция: массивы стен скрыты внутри `Maze`.
- Интерфейс и полиморфизм: `MazeGenerator` и `DfsMazeGenerator`, алгоритм генерации можно заменить.
- Неизменяемые данные: `record` для `Position`, `State`, `StepResult`.
- Перечисления: `Direction`, `CellType`.
- Композиция: `Simulation` содержит `Environment`, `Mouse` и `QLearningAgent`.
- Наследование: `MainFrame extends JFrame`, `MazePanel extends JPanel`.
- Разделение ответственности в духе MVC: `model`, `view`, `controller`.
